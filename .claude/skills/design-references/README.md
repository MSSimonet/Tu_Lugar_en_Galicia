## Referencia principal seleccionada: **Starbucks**

📄 [`starbucks/DESIGN.md`](starbucks/DESIGN.md)

### Por qué Starbucks encaja con Tu Lugar en Galicia

1. **Paleta cálida mediterránea**: El canvas crema de Starbucks (`#f2f0eb` Neutral Warm) es
   prácticamente idéntico en temperatura a `--color-niebla` y `--color-arena` del proyecto.
   El sistema verde profundo (House Green `#1E3932`) espeja `--color-atlantico`.
   El dorado `#cba258` (reservado solo para momentos de ceremony) equivale a `--color-laton`.

2. **Tipografía dual sans + serif editorial**: SoDoSans (sans primario) + Lander Tall (serif
   editorial para momentos expresivos) espeja exactamente la dualidad
   Cormorant Garamond titular / Plus Jakarta Sans UI del proyecto.

3. **Ritmo de bandas**: Cream hero → White content → Dark-green band → Cream footer
   es la misma estructura que usa el sitio. No es coincidencia estilística — es la misma
   lógica visual de "calidez como base, profundidad oscura como acento".

4. **Sofisticación sin frialdad**: El sistema Starbucks nunca es corporate-frío. Es cálido,
   comunitario, confiable — exactamente la voz del proyecto para familias que vuelven a casa.

### Cómo usar esta referencia en tareas futuras

Cuando se trabaje en diseño UI, invocar esta referencia así:

```
"Seguir el sistema Starbucks de .claude/skills/design-references/starbucks/DESIGN.md
como referencia de temperatura y estructura visual, adaptando colores al design system
propio del proyecto (--color-atlantico, --color-laton, --color-niebla, etc.)"
```

Puntos concretos a tomar de Starbucks:
- **Ritmo de bandas**: crema → blanco → verde oscuro → crema
- **Elevation**: sombras whisper-soft en 2–3 capas de baja opacidad, nunca una sola pesada
- **Dorado/latón**: reservado solo para momentos de valor / confianza / premium
- **Full-pill buttons**: el proyecto usa `var(--radius-pill)` — consistente con esto
- **Canvas cálido**: nunca blanco puro para fondos de sección — usar niebla/arena
