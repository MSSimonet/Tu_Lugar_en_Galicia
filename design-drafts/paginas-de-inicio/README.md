# /design-drafts/paginas-de-inicio — páginas de inicio completas

A diferencia de las 12 direcciones en `/design-drafts` (que eran header + hero +
3 tarjetas + specimen, para mostrar paleta/tipografía/animación en aislado),
estos 5 archivos son la **página de inicio completa**: hero, marcador de cifras,
ciudades, muro de llaves, testimonio, cómo funciona, FAQ, CTA final, footer y
widget de Gina — la misma estructura de secciones que tiene hoy el sitio real
(`app/page.tsx`), pero con 5 identidades visuales distintas.

Abrí cada `.html` directo en el navegador y recorré toda la página con scroll,
no solo el hero.

| Archivo | Dirección | Registro |
|---|---|---|
| `a-neboa-nocturna.html` | A ⭐ | Nocturno, técnico — negro + lima eléctrico |
| `d-camelia-en-invernada.html` | D ⭐ | Elegante, sereno — sage + vino, serif itálica |
| `e-cantiga-de-taberna.html` | E ⭐ | Cálido, social, nocturno-acogedor — mostaza + viño |
| `g-festa-da-romaria.html` | G | Maximalista, festivo — 3 colores vivos a la vez |
| `i-pedra-e-liquen.html` | I | Minimalista, silencioso — piedra + un solo verde |

⭐ = ya guardadas por el usuario como candidatas en la exploración anterior.

Elegidas para cubrir el espectro completo de energía/temperatura: de lo más
frío y tecnológico (A) a lo más cálido y ruidoso (G), pasando por lo elegante
(D), lo social (E) y lo silencioso (I). Ninguna se parece a otra.
